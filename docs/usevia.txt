======================================================================
Official VIA Guide
======================================================================

이 문서는 공식 VIA(https://usevia.app)를 직접 사용하는 경우의 안내입니다.
일반 사용자는 https://usekb.cc 를 권장합니다. usekb.cc에서는 각 메뉴 옆 Help로
같은 기능을 바로 확인할 수 있습니다.

----------------------------------------------------------------------
한국어
----------------------------------------------------------------------

스톡 VIA는 기본 설정을 지원합니다. 복잡한 고급 편집과 자동 갱신 상태 표시는
usekb.cc Custom 앱에서 지원합니다.

■ 공식 VIA 시작

키보드에 맞는 펌웨어 배포본에 동봉된 VIA JSON을 사용하십시오.

1. https://usevia.app 에 접속합니다.
2. SETTINGS에서 Show Design tab을 켭니다.
3. DESIGN -> Load Draft Definition에서 이 키보드의 VIA JSON을 불러옵니다.
4. CONFIGURE에서 KEYMAP, LIGHTING, FEATURE, TAPDANCE, SYSTEM을 설정합니다.

TAPDANCE 입력창에 직접 keycode를 넣을 때는 같은 폴더의 via_keycodes.txt를
참고하십시오. 키맵을 보관하려면 VIA의 SAVE + LOAD에서 백업하십시오.
USB 식별자(VID/PID)가 바뀐 펌웨어로 업데이트했다면 같은 배포의 VIA JSON을 다시
불러오고 Authorize device로 키보드 연결을 다시 허용하십시오.

■ VERSION

CONFIGURE -> SYSTEM -> VERSION은 이 키보드의 펌웨어 버전을 YYMMDDRn 형식으로
표시합니다. 연·월·일과 리비전을 키보드에서 읽어 오는 값이며 VIA에서 수정할 수
없습니다. 문제를 제보할 때 이 값을 함께 적어 두면 좋습니다.

■ MATRIX TEST

VIA의 Matrix Test에서 물리 매트릭스 눌림을 표시합니다. 이 기능을 위해 VIA Raw
HID를 사용할 수 있는 호스트 프로그램은 현재 눌린 매트릭스 위치를 조회할 수
있습니다. 신뢰할 수 있는 PC에서 사용하십시오.

■ TAPDANCE

CONFIGURE -> TAPDANCE에서 TD0~TD7을 설정한 뒤 KEYMAP에서 같은 TD 번호를
원하는 위치에 배치합니다. TD 키를 키맵에 배치해야 설정한 동작을 사용할 수 있습니다.

공식 VIA는 기본(Legacy) 모드의 다섯 항목만 편집합니다.
- On Tap: 짧게 탭했을 때의 키
- On Hold: 길게 눌렀을 때의 키
- On Double Tap: Term 안에 두 번 탭했을 때의 키
- Tap+Hold: 한 번 탭한 뒤 이어서 길게 눌렀을 때의 키
- Term: 동작을 판정하는 시간. 공식 VIA에서는 100~500ms를 20ms 단위로 선택합니다.

기본 모드에서 On Double Tap과 Tap+Hold를 비워 두면 키를 떼는 순간 탭을 입력하고,
Term은 홀드 판정에만 사용합니다. On Double Tap을 설정하면 두 번째 탭을 떼는
순간 입력합니다. 빈 슬롯이나 On Hold = KC_NO인 슬롯도 다섯 항목을 표시합니다.

고급 Tap Dance 설정은 웹브라우저에서 https://usekb.cc 에 접속하여 편집하십시오.
usekb.cc는 고급 설정을 지원하는 커스텀 VIA 앱입니다. Input start 모드,
정밀한 Term, 별도 Hold time, Hold on other key는 이 앱에서 설정합니다.
공식 VIA 화면에는 “Advanced settings: Visit usekb.cc”로 안내합니다.
이 주소는 일반 텍스트이므로 브라우저 주소창에 입력하여 접속하십시오.

고급 모드나 알 수 없는 모드의 슬롯은 공식 VIA에서 usekb.cc 안내만 표시합니다. 해당 슬롯의 동작과 시간은 usekb.cc에서 편집하십시오.
공식 VIA를 열거나 JSON을 교체해도 기본 모드로 전환하거나 저장값을 초기화하지
않습니다. 모드 선택창과 고급 타이밍 슬라이더는 공식 VIA에서 제공하지 않습니다.
다른 앱에서 설정을 바꾼 뒤 공식 VIA를 다시 사용할 때는 F5로 실제 값을 다시 읽으십시오.

■ SOCD

CONFIGURE -> FEATURE -> SOCD에서 서로 반대되는 두 키(좌/우, 상/하)를 지정하고,
두 키를 함께 누르고 있을 때 PC로 보낼 키를 Mode에서 고릅니다.

- Last Input: 나중에 누른 키만 보냅니다. 그 키를 떼면 아직 누르고 있는 다른
  키가 곧바로 다시 입력됩니다(스냅 탭). 기본값입니다.
- Neutral: 두 키 모두 보내지 않습니다.
- First Input: 먼저 누른 키를 유지합니다.
- Left/Up Priority, Right/Down Priority: 누른 순서와 상관없이 지정한 쪽을
  보냅니다.

키에는 일반 키나 modifier 키를 지정하십시오. 판정은 PC로 나가는 키를 기준으로
하므로 Tap Dance나 매크로가 낸 키에도 적용됩니다. 한 쌍의 두 칸에 같은 키를
넣거나 한 키를 두 쌍에 함께 넣으면 그 쌍은 동작하지 않습니다. 일부 게임과 대회는 SOCD 사용을 제한하므로 규정을
확인하십시오.

■ KKUK

CONFIGURE -> FEATURE -> KKUK에서 사용합니다. 일반 키 두 개 이상을 계속 누르면
눌린 키 묶음을 Delay/Repeat 설정에 따라 주기적으로 뗐다가 다시 누릅니다.
예를 들어 A, S, D를 계속 누르면 일반적인 "asdddd..." 자동 반복 대신 보통
"asdasdasd..."처럼 입력됩니다. 문자열 매크로나 매트릭스 ghosting 방지 기능이
아니며 SOCD에 지정한 키는 반복 대상에서 제외됩니다.

■ DEBOUNCE

CONFIGURE -> FEATURE -> DEBOUNCE에서 스위치 채터링 필터를 조정합니다.
기본값은 Balanced, 5 ms입니다. 한 번 눌렀는데 여러 번 입력되는 증상이 있다면
관련 시간을 조금씩 늘리십시오. 채터링 문제가 없다면 기본 설정을 유지하는 것을
권장합니다.

■ TAPPING

CONFIGURE -> FEATURE -> TAPPING에서 Mod-Tap/Layer-Tap의 탭·홀드 판정을
조정합니다. Tapping Term의 기본값은 200 ms입니다. 짧을수록 홀드가 빨리
걸리지만 빠른 타이핑이 의도치 않은 홀드로 판정될 수 있고, 길수록 안정적이지만
홀드가 늦게 들어옵니다.

- Permissive Hold: 다른 키를 눌렀다 뗄 때까지 탭·홀드 키를 계속 누르고 있으면
  홀드로 판정합니다.
- Hold On Other Key Press: 다른 키를 누르는 순간 바로 홀드로 판정합니다.
  더 빠르지만 굴려 치는 타건에서는 의도한 탭이 홀드가 될 수 있습니다.
- Retro Tapping: Term을 넘겨 눌렀더라도 그 사이 다른 키를 누르지 않았다면
  키를 뗄 때 탭을 입력합니다.

■ MOUSE

V261004R1부터 정수 단위 정밀 입력은 usekb.cc의 Precise values에서 제공합니다.
스톡 VIA는 가장 가까운 프리셋을 표시하며 조회만으로 정밀 값을 바꾸지 않습니다.
휠 가속은 시간이 0이면 Off, 나머지는 목표 속도 기준으로 Mild/Strong을 표시합니다.
프리셋을 선택하면 그 설정으로 변경됩니다.

CONFIGURE -> FEATURE -> MOUSE에서 Mouse Key 동작을 조정합니다. 키맵에
Mouse Key가 없으면 입력에 영향을 주지 않습니다. 값들이 서로 영향을 주므로
한 번에 하나씩 조정하는 것을 권장합니다.

- Cursor Acceleration: 시작 속도에서 최고 속도까지 가속하는 시간. Off면 고정 속도.
- Cursor Start Speed / Top Speed: 가속 시작/종료 시 한 스텝 이동 거리.
- Cursor Speed: Acceleration이 Off일 때 한 스텝 이동 거리.
- Cursor Steps Per Second: 초당 커서 이동 스텝 수. 메뉴의 /s는 초당 횟수입니다.
- Wheel Rate: 초당 스크롤 스텝 수.
- Wheel Acceleration: 누르고 있는 동안 스크롤 가속 정도.

메뉴의 Off는 가속하지 않는 일정 속도입니다. 속도 선택은 /s로 표시하며,
예를 들어 200 /s는 5ms 간격, 50 /s는 20ms 간격에 해당합니다.

■ ROLLOVER / NKRO

별도 NKRO 토글은 없습니다. 일반 HID 보고에서는 최대 20키 동시 입력을
항상 지원합니다. BIOS/KVM처럼 Boot Protocol을 요청하는 환경에서는 표준
8바이트 보고로 바뀌어 동시에 6키까지 전달합니다.

■ LIGHTING

CONFIGURE -> LIGHTING에서 현재 보드가 지원하는 RGB Row 또는 Underglow의
밝기, 효과, 색과 효과 속도를 조정합니다. Pulse 효과 이름은 다음과 같습니다.

- Pulse Off Press
- Pulse On Press
- Pulse Off Press (Hold)
- Pulse On Press (Hold)

Effect Speed는 Pulse에서만 표시되며 펄스 길이는 5 + 값 ms입니다.
0은 5 ms, 255는 260 ms이고 기본값 15는 20 ms입니다. Hold 효과는 이 시간이
끝나도 누른 키가 하나라도 눌려 있으면 유지됩니다. 효과를 다시 고르거나 RGB를
끄거나 RGB 절전에 들어가면 진행 중인 Pulse는 끝나고, 절전 중에 누른 키는
Pulse를 만들지 않습니다. 일반 Breathing 1~4 등의
속도는 Effect 번호로 선택합니다. 지원 효과에서 Velocikey를 켜면 입력 속도에
따라 속도가 변합니다.
Indicators의 Indicator(두 개인 보드는 Indicator 1·2)에서 Caps Lock / Scroll
Lock / Num Lock 중 표시할 상태를 고르고 Indicator Brightness와 Indicator
Color를 설정합니다. 0번 값은 표시 LED를 조명과 함께 쓰는 경우
RGB Effect(조명 효과가 그대로 보임), 전용 LED인 경우 Off입니다.

■ SYSTEM

USB POLLING:
Boot Polling Mode는 선택할 설정이며 재부팅 후 다시 읽으면 저장한 모드를 표시합니다.
실제 FS/HS 연결의 폴링 설정은 usekb.cc Custom 앱에서 확인하십시오.
CONFIGURE -> SYSTEM -> USB POLLING에서 1 kHz (FS), 2 kHz (HS), 4 kHz (HS),
8 kHz (HS) 중 선택한 뒤 Apply를 사용합니다. 선택만으로는 적용되지 않으며
Apply는 같은 모드를 다시 선택해도 키보드를 재시작합니다. 분리 전 최소 500ms 동안
입력과 VIA 처리를 계속하고, 저장·응답 전송 완료 뒤 분리하여 재부팅합니다. 기본값은 1 kHz (FS)입니다. 1 kHz는 어느 포트에서나 사용할 수
있지만 고속 모드는 USB High Speed로 협상되는 포트가 필요하며, 허브나 전면 패널
포트에서는 사용할 수 없는 경우가 있습니다.

SLEEP:
CONFIGURE -> SYSTEM -> SLEEP의 RGB Sleep은 기본 On입니다. 끄면 유휴 시간,
USB 절전, 호스트 소실에 따른 자동 RGB 절전 전체를 비활성화합니다. On일 때만
시간 설정이 보이며, 마지막 입력 뒤 1/3/5/10/30/60분 중 선택합니다. 기본값은
10분입니다. 토글을 꺼도 시간 값은 보존됩니다. 자동 절전으로 꺼졌다면 입력이나 정상적인
호스트 복귀로 켜지지만, 사용자가 끈 RGB를 자동으로 켜지는 않습니다.

BOOT:
Jump To BOOT는 켜는 즉시 부트로더로 진입합니다. 실행 후 항상 꺼진 값으로
보이는 것이 정상입니다.
왼쪽 위 키를 누른 채 USB를 연결해도 부트로더에 진입합니다.

■ EEPROM CLEAN

기존 배포 펌웨어에는 10초 확인 제한이 남아 있습니다. 해당 버전에서는 세 토글을
10초 안에 모두 켜십시오. 시간 제한 제거는 새 펌웨어 설치 후 적용됩니다.

CONFIGURE -> SYSTEM -> EEPROM에서 세 확인 토글을 모두 켜면 저장된
키맵과 모든 설정을 초기화하고 키보드가 재시작합니다.
실행 전 VIA SAVE + LOAD로 키맵을 백업하십시오.

English
----------------------------------------------------------------------

Stock VIA supports basic configuration. Use the Custom app at usekb.cc for
advanced editing and automatically refreshed status.

■ Starting Official VIA

Use the VIA JSON bundled with the firmware release for your keyboard.

1. Open https://usevia.app.
2. Enable Show Design tab in SETTINGS.
3. In DESIGN -> Load Draft Definition, load the VIA JSON for this keyboard.
4. Use CONFIGURE for KEYMAP, LIGHTING, FEATURE, TAPDANCE, and SYSTEM.

See via_keycodes.txt in the same folder when entering keycodes directly into
TAPDANCE fields. Use VIA SAVE + LOAD to back up a keymap you want to keep.
After an update that changes the USB identity (VID/PID), load the VIA JSON from
the same release again and use Authorize device to reconnect the keyboard.

■ VERSION

CONFIGURE -> SYSTEM -> VERSION shows this keyboard's firmware version in
YYMMDDRn form. The year, month, day, and revision are read from the keyboard and
cannot be changed in VIA. Include this value when reporting a problem.

■ MATRIX TEST

VIA Matrix Test shows physical matrix presses. A host program with access to VIA
Raw HID can therefore query currently pressed matrix positions. Use the keyboard
with trusted host software.

■ TAPDANCE

Configure TD0 through TD7 in CONFIGURE -> TAPDANCE, then place the matching
TD number on a key in KEYMAP. A configured slot works only after its TD key is placed.

Official VIA edits five fields for slots in basic (Legacy) mode:
- On Tap: key for a short tap
- On Hold: key for a held press
- On Double Tap: key for two taps inside Term
- Tap+Hold: key for a tap followed by a hold
- Term: decision time; official VIA offers 100..500 ms in 20 ms steps.

In basic mode, leaving On Double Tap and Tap+Hold empty sends a tap on release
and uses Term only for the hold decision. With On Double Tap assigned, the second
release sends that action. Empty slots and slots with On Hold = KC_NO show all five fields.

For advanced Tap Dance settings, visit https://usekb.cc in your web browser.
usekb.cc is the custom VIA app supporting advanced settings. Use it for Input
start modes, precise Term values, separate Hold time, and Hold on other key.
Official VIA displays “Advanced settings: Visit usekb.cc”. The address is plain
text; enter it in your browser's address bar to open the app.

Advanced and unknown-mode slots show only the usekb.cc guidance in official VIA. Edit that slot's actions and timing at usekb.cc.
Opening official VIA or replacing its JSON does not switch the mode or reset stored
settings. Official VIA does not offer mode selection or advanced timing sliders.
After changing settings in another app, reload official VIA with F5 to read actual values.

■ SOCD

Assign each opposing key pair (left/right, up/down) in CONFIGURE -> FEATURE ->
SOCD, then choose in Mode what reaches the computer while both keys are held.

- Last Input: only the key pressed later is sent. Releasing it sends the key
  still held again at once (snap tap). This is the default.
- Neutral: neither key is sent.
- First Input: the key pressed first stays.
- Left/Up Priority, Right/Down Priority: the chosen side is sent regardless of
  press order.

Use ordinary keyboard or modifier keycodes. SOCD judges the keys going to the
computer, so it also applies to keys sent by Tap Dance or a macro. A pair with
the same key in both slots, or a key used in both pairs, does nothing. Some games and tournaments restrict SOCD; check their
rules.

■ KKUK

Use CONFIGURE -> FEATURE -> KKUK. While two or more ordinary keys remain held,
KKUK periodically releases the held group and presses it again according to
Delay/Repeat. For example, holding A, S, and D usually produces "asdasdasd..."
instead of the ordinary "asdddd..." auto-repeat. This is neither a string macro
nor matrix ghosting prevention. Keys assigned to SOCD are excluded.

■ DEBOUNCE

Adjust switch-chatter filtering in CONFIGURE -> FEATURE -> DEBOUNCE. The
default is Balanced, 5 ms. If one physical press sometimes produces multiple
inputs, increase the relevant delay a little at a time. If there is no chatter,
keeping the default settings is recommended.

■ TAPPING

Adjust Mod-Tap/Layer-Tap tap-hold decisions in CONFIGURE -> FEATURE -> TAPPING.
The default Tapping Term is 200 ms. Shorter makes holds trigger sooner but can
turn fast typing into accidental holds; longer is safer but makes the hold
arrive later.

- Permissive Hold: while the tap-hold key is still held, pressing and releasing
  another key makes it a hold.
- Hold On Other Key Press: another key press makes it a hold immediately. This
  is earlier, but rolling key presses can turn intended taps into holds.
- Retro Tapping: if the key is held past Term and released without another key
  press, the release still sends the tap.

■ MOUSE

From V261004R1, integer precision is available through Precise values at usekb.cc.
Stock VIA displays the nearest preset; reads never change precise settings.
Wheel acceleration shows Off for zero ramp, otherwise Mild/Strong by the nearest
target speed, ignoring duration (ties choose Mild). Selecting a preset writes it.

Configure Mouse Keys in CONFIGURE -> FEATURE -> MOUSE. These settings do not
affect typing unless Mouse Key keycodes are present in the keymap. The values
affect one another, so adjusting one at a time is recommended.

- Cursor Acceleration: time from start speed to top speed; Off uses fixed speed.
- Cursor Start Speed / Top Speed: distance per step at start/end of acceleration.
- Cursor Speed: distance per step while Acceleration is Off.
- Cursor Steps Per Second: cursor movement steps per second.
- Wheel Rate: scroll steps per second.
- Wheel Acceleration: how strongly scrolling accelerates while held.

Off means constant speed without acceleration. Rate options use /s (steps per
second): 200 /s corresponds to a 5 ms interval and 50 /s to 20 ms.

■ ROLLOVER / NKRO

There is no separate NKRO toggle. Normal HID reporting always supports up to
20 simultaneous keys. A BIOS/KVM that requests the Boot Protocol receives the
standard 8-byte boot report with up to six keys instead.

■ LIGHTING

Use CONFIGURE -> LIGHTING for the board's RGB Row or Underglow brightness,
effect, colour, and effect speed. Pulse effect names are:

- Pulse Off Press
- Pulse On Press
- Pulse Off Press (Hold)
- Pulse On Press (Hold)

Effect Speed appears only for Pulse and sets duration to 5 + value ms: 0 is
5 ms, 255 is 260 ms, and the default 15 is 20 ms. Hold effects continue after
that duration while any pressed key remains down. Reselecting an effect, RGB
OFF, or RGB Sleep ends the pulse in progress, and a key pressed during Sleep
does not pulse. For ordinary effects such as
Breathing 1–4, choose the numbered Effect variant. Velocikey changes speed with
typing speed for supported effects.
In Indicators, Indicator (Indicator 1 and 2 on boards with two) chooses Caps
Lock, Scroll Lock, or Num Lock, then Indicator Brightness and Indicator Color
apply. Value 0 is RGB Effect when the indicator shares the lighting LEDs
and shows the lighting effect, or Off when it uses a dedicated LED.

■ SYSTEM

USB POLLING:
Boot Polling Mode is the selected setting; a fresh read after reboot shows the
stored mode. Use the Custom app at usekb.cc to inspect the FS/HS endpoint setting.
Choose 1 kHz (FS), 2 kHz (HS), 4 kHz (HS), or 8 kHz (HS) in CONFIGURE ->
SYSTEM -> USB POLLING and use Apply. Selection alone does not apply the mode.
Apply restarts the keyboard even when selecting the same mode. Input and VIA
service continue for at least 500 ms before disconnect; pending storage and
response transmission must finish before teardown. The default is 1 kHz (FS). 1 kHz works on any port; the high-speed
rates require a port that negotiates USB High Speed, which hubs and front-panel
headers often cannot.

SLEEP:
RGB Sleep in CONFIGURE -> SYSTEM -> SLEEP is On by default. Turning it off
disables automatic RGB sleep for idle timeout, USB suspend and host loss.
The timeout control is shown only while RGB Sleep is on. Choose
1/3/5/10/30/60 minutes of inactivity; the default is 10 minutes. Turning the
toggle off keeps that timeout. Input or normal host recovery wakes
automatically sleeping RGB, but does not turn on RGB disabled by the user.

BOOT:
Jump To BOOT enters the bootloader as soon as it is switched on and normally
reads back off after the action.
Holding the top-left key while plugging in USB also enters the bootloader.

■ EEPROM CLEAN

Existing release firmware still has a ten-second confirmation limit: turn on
all three toggles within ten seconds. Removing that limit requires installing
updated firmware.

Turn on all three confirmation toggles in CONFIGURE -> SYSTEM -> EEPROM
to erase the stored keymap and every setting and restart the
keyboard. Back up the keymap with VIA SAVE + LOAD before running CLEAN.
